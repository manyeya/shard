One file, eight ways at once.

A normal download is one connection pulling one long stream, so the file is only as fast as that one connection. Shard opens several and keeps every one of them busy until the last byte.

  1. 1

    Ask

    Shard asks the server for one byte, which tells it the file's size, its name and whether it can be fetched in pieces.

  2. 2

    Split

    The first connection takes the whole file. Each one that opens after it takes the back half of the part with the most left.

  3. 3

    Take over

    A connection that finishes early splits the slowest part again, so the last few percent never crawl along on one connection.

  4. 4

    Write down

    Every second it notes how far each part got, only once those bytes are on disk. Stop anywhere and the next run carries on.

Built for the downloads that go wrong.

Backs off when a server says no, then tries again

Some servers allow only a few connections and answer the rest with “too many requests”. Shard drops the refused ones and carries on. Half a minute later it tries one more, waiting twice as long each time it's turned away.

Picks up where it stopped

Pause, quit, crash or sleep. The next run checks the file hasn't changed on the server and carries on.

Opening it the first time

macOS: Shard isn't signed by Apple yet. Open System Settings, then Privacy and Security, and choose Open Anyway.

Windows: if SmartScreen holds it back, choose More info, then Run anyway.

Linux: install the .deb with sudo apt install ./shard_*.deb, or unpack the tarball anywhere and run ./shard.

Adding the extension

Unzip it somewhere it can stay, open chrome://extensions (or arc://extensions) and turn on Developer mode.

Questions

Is it free?

Yes. The code is on GitHub, and there's nothing to buy or sign up for.

Will it make every download faster?

Only when one connection isn't using your whole line, which is common: many servers and routes limit each connection. If one connection already fills it, you still get resuming, the queue and the rest.

Does it send anything about me anywhere?

No. Shard talks to the servers you download from, and to GitHub to check for updates. There's no account, no tracking and no analytics.

Where do files go?

Your Downloads folder, unless you choose another, ask to be asked each time, or sort files into folders by kind.

A link stopped working halfway. Do I start again?

No. Right-click the download, choose Refresh link and paste a fresh link to the same file. If it's the same size, Shard keeps everything it already has.

How does combining networks work?

Each connection is tied to one of your networks, taking them in turn, so a download's parts come in over all of them. You need two working connections, such as Wi-Fi and Ethernet, or Wi-Fi and a phone over USB.

How does it update?

It checks for a new version every six hours, downloads it quietly, checks its signature and asks you to restart. Nothing changes until you choose to.
